Ubuntu - Instalação do TeamViewer Host

Instalação do TeamViewer Host via pacote oficial .deb, para acesso remoto não assistido, sem interface gráfica.

Requisitos: Ubuntu 24.04 LTS (Noble Numbat) ou 26.04 LTS (Resolute Raccoon) · 64 bits · acesso sudo

Atenção: o TeamViewer completo e o TeamViewer Host não podem conviver no mesmo sistema. Se o TeamViewer completo já estiver instalado, remova-o antes com sudo apt remove teamviewer.

Passo 1 Atualizar a lista de pacotes 
sudo apt update
Passo 2 Baixar o pacote do TeamViewer Host 
wget -O teamviewer-host_amd64.deb https://download.teamviewer.com/download/linux/teamviewer-host_amd64.deb
Passo 3 Instalar o pacote 
sudo apt install ./teamviewer-host_amd64.deb -y
Passo 4 Verificar se o serviço está ativo 
systemctl status teamviewerd
Passo 5 Verificar o ID do TeamViewer (necessário para conexão remota) 
sudo teamviewer info

Instalação automática via script

Baixe e execute o script para instalar o TeamViewer Host automaticamente, sem copiar e colar comandos.

Script Executar instalação automática 
wget -qO- https://ti.raimundo.com.br/scripts/instalar_teamviewer_host_ubuntu.sh | sudo bash

Nota: O script verifica a arquitetura, detecta conflitos e exibe o progresso em cada etapa.

Baixar e executar manualmente

Alternativa: baixe o script e execute pelo terminal local. Útil se preferir conferir o conteúdo antes de executar.

↓ Baixar instalar_teamviewer_host_ubuntu.sh
Terminal Executar o script baixado 
sudo bash ~/Downloads/instalar_teamviewer_host_ubuntu.sh

Nota: Abra o terminal e execute o comando acima. Ajuste o caminho se baixou em outra pasta.
