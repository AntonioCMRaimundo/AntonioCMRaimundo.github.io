Google Chrome no Ubuntu 24.04 LTS

Instalação do Google Chrome via repositório oficial do Google, garantindo atualizações automáticas pelo apt.

Requisitos: Ubuntu 24.04 LTS (Noble Numbat) · 64 bits · acesso sudo

Passo 1 Atualizar a lista de pacotes 
sudo apt update
Passo 2 Instalar dependências 
sudo apt install ca-certificates curl -y
Passo 3 Importar chave GPG do Google 
curl -fsSL https://dl.google.com/linux/linux_signing_key.pub | sudo gpg --dearmor --yes -o /usr/share/keyrings/google-chrome.gpg
Passo 4 Adicionar repositório oficial do Google Chrome 
printf '%s\n' 'Types: deb' 'URIs: https://dl.google.com/linux/chrome/deb/' 'Suites: stable' 'Components: main' 'Architectures: amd64' 'Signed-By: /usr/share/keyrings/google-chrome.gpg' | sudo tee /etc/apt/sources.list.d/google-chrome.sources > /dev/null
Passo 5 Atualizar APT com novo repositório 
sudo apt update
Passo 6 Verificar se o pacote está disponível 
apt-cache policy google-chrome-stable
Passo 7 Instalar o Google Chrome 
sudo apt install google-chrome-stable -y
Passo 8 Verificar versão instalada 
google-chrome --version
Passo 9 Iniciar o Google Chrome 
google-chrome

Instalação automática via script

Baixe e execute o script para instalar o Chrome automaticamente, sem copiar e colar comandos.

Script Executar instalação automática 
curl -fsSL https://ti.raimundo.com.br/scripts/instalar_chrome_ubuntu2404.sh | sudo bash

Nota: O script verifica a arquitetura, detecta conflitos e exibe o progresso em cada etapa.
