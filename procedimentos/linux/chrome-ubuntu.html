Google Chrome no Ubuntu 24.04 LTS

Instalação do Google Chrome via repositório oficial do Google, garantindo atualizações automáticas pelo apt.

Requisitos: Ubuntu 24.04 LTS (Noble Numbat) · 64 bits · acesso sudo

Passo 1 Atualizar o sistema 
sudo apt update && sudo apt upgrade -y
Passo 2 Instalar dependências 
sudo apt install -y wget curl gnupg2 apt-transport-https ca-certificates
Passo 3 Baixar a chave de assinatura do Google 
wget -q -O - https://dl.google.com/linux/linux_signing_key.pub | \
  sudo gpg --dearmor -o /usr/share/keyrings/google-chrome.gpg
Passo 4 Adicionar o repositório oficial 
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/google-chrome.gpg] \
  http://dl.google.com/linux/chrome/deb/ stable main" | \
  sudo tee /etc/apt/sources.list.d/google-chrome.list
Passo 5 Atualizar a lista de pacotes 
sudo apt update
Passo 6 Instalar o Google Chrome Stable 
sudo apt install -y google-chrome-stable
Passo 7 Verificar a versão instalada 
google-chrome --version
Passo 8 Localizar o executável 
which google-chrome
Passo 9 Iniciar o Google Chrome 
google-chrome &
