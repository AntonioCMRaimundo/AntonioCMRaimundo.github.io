Ubuntu - Criação de Usuários Comuns

O script cria contas de usuário comuns, sem privilégios de administrador (sudo). Cada conta recebe uma senha temporária aleatória, que expira imediatamente: o próprio usuário define a senha definitiva no primeiro login.

Requisitos: Ubuntu 24.04 LTS ou 26.04 LTS · acesso sudo

Segurança: o script nunca adiciona o novo usuário ao grupo sudo, em nenhum modo. Se sudo aparecer na lista de grupos extras, ele é ignorado e o script emite um aviso.

Senha temporária: é exibida uma única vez na tela, junto com o login, ao final da criação de cada usuário. Ela não é gravada em arquivo nem registrada em log. Anote-a e repasse-a ao usuário.

Modos de operação

Execute os comandos a partir da pasta onde o script foi baixado (por exemplo, cd ~/Downloads). O script está disponível na seção "Baixar o script" mais abaixo.

Modo 1 Interativo 
sudo bash criar_usuario_ubuntu.sh --interativo

Nota: O script pergunta o nome completo, sugere um login (primeira letra do primeiro nome + sobrenome, minúsculo e sem acento), pergunta os grupos extras (opcional) e pede confirmação antes de criar a conta.

Modo 2 CSV com confirmação 
sudo bash criar_usuario_ubuntu.sh --csv usuarios.csv

Nota: O script lê o arquivo inteiro, lista todos os usuários que serão criados (nome, login e grupos) e pede uma única confirmação. Depois processa linha a linha: se uma linha falhar (por exemplo, login já existente), ela é ignorada e as demais continuam. Formato: nome_completo,login,grupos_extras, com cabeçalho opcional e grupos separados por ; dentro do campo.

Arquivo Exemplo de usuarios.csv 
nome_completo,login,grupos_extras
Maria Souza,msouza,audio;video
João da Silva,jsilva,
Carlos Lima,clima,plugdev

Nota: Os campos não aceitam vírgula dentro do valor. Linhas em branco e linhas iniciadas por # são ignoradas. Grupos que não existem no sistema são ignorados com aviso.

Modo 3 Linha única 
sudo bash criar_usuario_ubuntu.sh msouza "Maria Souza" "audio;video"

Nota: Formato: <login> ["Nome Completo"] [grupos_extras]. Só o login é obrigatório: se o nome for omitido, o login é usado como nome; se os grupos forem omitidos, nenhum grupo extra é aplicado (use ; para separar mais de um). Não há confirmação adicional.

Modo 4 Detecção automática (sem argumentos) 
sudo bash criar_usuario_ubuntu.sh

Nota: Sem argumentos, o script procura o arquivo usuarios.csv na mesma pasta em que o script está. Se encontrar, usa o modo 2 (CSV com confirmação); se não encontrar, usa o modo 1 (interativo).

Baixar o script

Baixe o script e execute pelo terminal local. Como o script pode pedir dados durante a execução (modo interativo) e cria contas no sistema, não é executado direto pela internet: baixe e confira o conteúdo antes de executar.

↓ Baixar criar_usuario_ubuntu.sh
Terminal Executar o script baixado 
sudo bash ~/Downloads/criar_usuario_ubuntu.sh

Nota: Abra o terminal e execute o comando acima. Ajuste o caminho se baixou em outra pasta.
