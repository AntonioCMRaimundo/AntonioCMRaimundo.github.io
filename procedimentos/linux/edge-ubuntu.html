Microsoft Edge no Ubuntu 24.04 LTS

Instalação do Microsoft Edge via repositório APT oficial da Microsoft (packages.microsoft.com), garantindo atualizações automáticas via apt.

Requisitos: Ubuntu 24.04 LTS (Noble Numbat) · 64 bits · acesso sudo

Passo 1 Atualizar a lista de pacotes 
sudo apt update
Passo 2 Instalar dependências 
sudo apt install ca-certificates curl -y
Passo 3 Importar chave GPG da Microsoft 
curl -fsSL https://packages.microsoft.com/keys/microsoft.asc | sudo gpg --dearmor --yes -o /usr/share/keyrings/microsoft-edge.gpg
Passo 4 Adicionar repositório oficial do Microsoft Edge 
printf '%s\n' 'Types: deb' 'URIs: https://packages.microsoft.com/repos/edge' 'Suites: stable' 'Components: main' 'Architectures: amd64' 'Signed-By: /usr/share/keyrings/microsoft-edge.gpg' | sudo tee /etc/apt/sources.list.d/microsoft-edge.sources > /dev/null
Passo 5 Atualizar APT com novo repositório 
sudo apt update
Passo 6 Verificar se o pacote está disponível 
apt-cache policy microsoft-edge-stable
Passo 7 Instalar o Microsoft Edge 
sudo apt install microsoft-edge-stable -y
Passo 8 Verificar versão instalada 
microsoft-edge --version
Passo 9 Iniciar o Microsoft Edge 
microsoft-edge

Instalação automática via script

Baixe e execute o script para instalar o Edge automaticamente, sem copiar e colar comandos.

Script Executar instalação automática 
bash <(curl -fsSL https://ti.raimundo.com.br/scripts/instalar_edge_ubuntu2404.sh)

Nota: O script verifica a arquitetura, detecta conflitos e exibe o progresso em cada etapa.
