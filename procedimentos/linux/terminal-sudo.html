Ubuntu - Terminal com privilégios de administrador

No Ubuntu, não existe "Terminal como Administrador" como no Windows. O equivalente é usar o comando sudo antes de cada comando, ou abrir uma sessão de superusuário.

Opção 1 Usar sudo em um comando específico (recomendado) 
sudo [comando]

Executa apenas aquele comando como administrador. Exemplo: sudo apt update

Opção 2 Abrir sessão completa como superusuário 
sudo -i

Abre um terminal com todos os comandos rodando como root. O prompt muda de $ para #. Digite exit para voltar ao usuário normal. Use com cautela.

Opção 3 Verificar se você tem permissão sudo 
sudo -l

Lista os comandos que seu usuário tem permissão de executar como sudo.

Opção 4 Adicionar usuário ao grupo sudo (requer outro admin) 
sudo usermod -aG sudo [seu-usuario]

Necessário quando o usuário não tem permissão sudo. Requer logout e login para ter efeito.

⚠ Atenção: Usar sudo incorretamente pode danificar o sistema. Sempre verifique o comando antes de executar.
