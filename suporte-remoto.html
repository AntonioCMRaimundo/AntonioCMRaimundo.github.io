Suporte Remoto

Para iniciar uma sessão de suporte remoto, baixe e execute o aplicativo correspondente ao seu caso. O técnico irá orientá-lo durante todo o processo.

Tenha em mãos o ID e a senha gerados pelo aplicativo para informar ao técnico.

↓ TeamViewer Host ↓ Quick Support

Qual versão baixar?

  • Host Instalação permanente — indicado para computadores que precisam de acesso frequente.
  • Quick Support Sem instalação — execute diretamente para uma sessão pontual de suporte.
